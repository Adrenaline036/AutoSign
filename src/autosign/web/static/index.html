仅在 HTTPS 或可信 VPN/LAN 中使用。内容包含登录令牌；AutoSign 不会回显，也不会写入日志。
如何从 Chrome 复制 accountStore3
  1. 在已经登录 VikACG 的那个 Chrome 标签页按 F12，打开“应用 / Application”。
  2. 先展开“存储 / Storage”下的 本地存储空间 / Local Storage， 选择 `https://www.vikacg.com`；不要选择 Cookies。
  3. 在右侧找到键名严格等于 accountStore3 的一行，复制完整 Value； 当前网页版通常保存在 Local Storage。
  4. 旧版会话也可能存放在 IndexedDB 的“localforage → keyvaluepairs”中； 这时 accountStore3 是右侧记录表中的 Key，而不是数据库名称。
  5. 不要复制省略号、Cookie 或其他网站的数据。两个位置都没有时， 请取消并重新使用实时浏览器登录。
